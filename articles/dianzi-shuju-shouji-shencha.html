电子数据的收集提取与审查判断：绝对排除、可补正瑕疵与身份同一性的证据链

荣郑律师 · 湖北立丰律师事务所 · 2026年10月

一、结论先行：电子数据的排除分"绝对排除"与"可补正"两层

电子数据已经是绝大多数刑事案件的核心证据，但它的取证规范并不是"违反即排除"。现行规则建立一个双层结构，可以直接记：

  1. 真实性无法保证的，绝对排除。电子数据系篡改、伪造或者无法确定真伪的；有增加、删除、修改等情形影响真实性的；其他无法保证真实性的，不得作为定案的根据（《关于办理刑事案件收集提取和审查判断电子数据若干问题的规定》第二十八条）。这一类没有补正空间。
  2. 程序瑕疵的，可以补正或作出合理解释。未以封存状态移送的；笔录或者清单上没有侦查人员、电子数据持有人（提供人）、见证人签名或者盖章的；对电子数据的名称、类别、格式等注明不清的；有其他瑕疵的——经补正或者作出合理解释的可以采用，不能补正或者作出合理解释的，不得作为定案的根据（第二十七条）。
  3. 合法性审查有四项硬指标。是否由二名以上侦查人员进行、取证方法是否符合技术标准；是否附有笔录、清单并经签名盖章；是否由符合条件的人员担任见证人、是否录像；电子数据检查是否通过写保护设备接入、是否制作备份（第二十四条）。
  4. 与非法证据排除规则衔接。《刑事诉讼法》第五十六条规定，收集物证、书证不符合法定程序，可能严重影响司法公正的，应当予以补正或者作出合理解释；不能补正或者作出合理解释的，对该证据应当予以排除。电子数据在证据种类上不属于物证、书证，但其取证程序的违法性审查可参照该条精神，具体适用方式实务中存在争议。

三、真实性审查的五项内容

对电子数据是否真实，应当着重审查：是否移送原始存储介质，无法封存、不便移动时有无说明原因并注明收集提取过程及原始介质存放地点或者数据来源；是否具有数字签名、数字证书等特殊标识；收集提取过程是否可以重现；如有增加、删除、修改等情形是否附有说明；完整性是否可以保证（第二十二条）。

完整性验证则要看五项：原始存储介质的扣押、封存状态；收集提取过程与录像；完整性校验值比对；与备份数据比较；冻结后的访问操作日志（第二十三条）。校验值是最硬的一项：没有校验值，就无法证明送检的数据与提取时的数据同一；校验值不一致，则直接落入第二十八条的绝对排除。

四、身份同一性与关联性

电子数据最常见的辩点不是"数据假"，而是"这个账号不是他用的"。规则对此有明确指引：认定犯罪嫌疑人、被告人的网络身份与现实身份的同一性，可以通过核查相关 IP 地址、网络活动记录、上网终端归属、相关证人证言以及犯罪嫌疑人、被告人供述和辩解等进行综合判断；认定其与存储介质的关联性，可以通过核查证人证言及供述等进行综合判断（第二十五条）。

条文用的是"综合判断"，意味着不能仅凭账号昵称、头像、绑定手机号就认定身份。设备 IMEI、MAC 地址、登录 IP 与基站信息、支付账户实名信息，才是可以相互印证的客观连接点。若卷宗中仅有账号截图而无设备与网络痕迹，同一性认定缺乏基础。

五、鉴定与专门性问题

对电子数据涉及的专门性问题难以确定的，由司法鉴定机构出具鉴定意见，或者由公安部指定的机构出具报告；检察院直接受理的案件，也可以由最高人民检察院指定的机构出具报告（第十七条）。对鉴定意见有异议的，可以申请法院通知鉴定人出庭；经通知拒不出庭的，鉴定意见不得作为定案的根据（第二十六条）。

需要注意报告与鉴定意见的区别：公安部指定机构出具的是"报告"，不是司法鉴定意见，其证据属性与审查标准不同。对报告提出异议时，同样可以申请通知出具人出庭，参照适用前三款规定（第二十六条第四款）。

六、辩护操作清单

  1. 先看有没有原始介质。有封存、有照片、有拆封录像，才有完整性讨论的基础；扣押清单缺失的，直接质疑来源。
  2. 再比校验值。提取时计算的校验值、移送时的校验值、鉴定时的校验值，三者应一致。不一致的，要求说明原因。
  3. 查见证人与录像。见证人不适格且无录像的，属于第二十七条第（三）项瑕疵，主张不能补正。
  4. 查检查环节。是否使用写保护设备、是否对备份而非原始介质进行检查。直接读写原始介质的，可能造成数据变动。
  5. 查同一性证据链。账号与人的连接点是否只有口供；仅有口供而无客观痕迹的，主张证明不足。
  6. 查数据完整性缺口。聊天记录是否只提取了片段、是否有选择性导出、时间戳是否连续。片段性数据容易被断章取义。
实务要点：提出排除申请要注意时机。依《刑事诉讼法》第五十六条第二款，当事人及其辩护人、诉讼代理人有权申请排除以非法方法收集的证据，应当提供相关线索或者材料。开庭前提出并附具体线索（页码、笔录缺项、校验值差异），比在法庭上概括质疑"取证程序违法"有效得多。

七、常见问题

问：公安机关只提供微信聊天记录截图，没有原始手机，能作为定案依据吗？

要看是否符合第九条的例外。无法扣押原始介质的，应在笔录中注明原因、存放地点或来源，并计算完整性校验值；未注明原因、无校验值的，属于程序瑕疵，可主张不能补正而排除（第二十七条）。

问：手机没有封存，直接开机提取，怎么办？

属于第八条封存义务的违反。若同时无录像、无校验值，真实性无法保证，可主张落入第二十八条；若仅封存不规范但数据可重现、校验值一致，通常认定为可补正瑕疵。

问：见证人是辅警，算合格见证人吗？

存在争议。规则要求"符合条件的人员"担任见证人，未明确排除辅警。若见证人系办案单位工作人员，独立性不足，可主张第十五条瑕疵并要求录像佐证；实务中存在争议。

问：聊天记录只截取了几页，能要求提供完整记录吗？

可以。片段性数据影响真实性与完整性判断，可依第二十二条、第二十三条要求出示原始介质或完整备份，并申请当庭展示（第二十一条）。

问：鉴定人不出庭，鉴定意见一定不能采信吗？

经人民法院通知，鉴定人拒不出庭作证的，鉴定意见不得作为定案的根据（第二十六条第二款）。注意前提是"经通知"且"拒不出庭"，仅未通知的不适用。

问：电子数据被排除后，还能用其他证据定罪吗？

可以。排除的是该项证据，不是整个案件。但若全案仅依赖被排除的电子数据，则据以定案的证据不足，应作有利于被告人的处理。
