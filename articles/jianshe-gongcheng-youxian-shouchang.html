工程款追索的路径选择：价款优先受偿权、质量反诉应对与实际施工人主张

荣郑律师 · 湖北立丰律师事务所 · 2026年9月

一、结论先行：三条路径与一个期限

工程款被拖欠后，承包人手里可用的工具不止一个，但每一条路径都有独立的成立条件，选错顺序会直接影响回款效率。三条路径可以直接记：

  1. 路径一：建设工程价款优先受偿权。与发包人订立建设工程施工合同的承包人，依据《民法典》第八百零七条请求其承建工程的价款就工程折价或者拍卖的价款优先受偿的，人民法院应予支持（《最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释（一）》第三十五条）。该权利优于抵押权和其他债权（第三十六条）。
  2. 路径二：普通工程款请求权加利息。依施工合同约定主张工程款本金，同时对欠付工程价款主张利息；利息计付标准有约定的从约定，没有约定的按同期同类贷款利率或者同期贷款市场报价利率计息（第二十六条）。
  3. 路径三：实际施工人主张。实际施工人以转包人、违法分包人为被告起诉的，人民法院应当依法受理；以发包人为被告主张权利的，人民法院应当追加转包人或者违法分包人为本案第三人，在查明发包人欠付转包人或者违法分包人建设工程价款的数额后，判决发包人在欠付建设工程价款范围内对实际施工人承担责任（第四十三条）。

关于期限，只有一条硬约束需要牢记：承包人应当在合理期限内行使建设工程价款优先受偿权，但最长不得超过十八个月，自发包人应当给付建设工程价款之日起算（第四十一条）。十八个月是不变期间，逾期即丧失优先受偿权，只剩普通债权。

实务要点：十八个月的起算点是"发包人应当给付建设工程价款之日"，而这个日期本身往往就是争议焦点。切记不要等到结算审核完毕、双方反复确认之后再计算期限——起算点的确定不以结算完成为前提。

二、优先受偿权的成立要件

主张优先受偿权，需要同时满足四项要件：

  1. 主体适格：必须是"与发包人订立建设工程施工合同的承包人"。这一限定意味着，实际施工人、转包关系中的次承包人、违法分包关系中的分包人，原则上不享有建设工程价款优先受偿权（第三十五条）。这是实务中最常见的误区。
  2. 工程质量合格。建设工程质量合格，承包人请求其承建工程的价款就工程折价或者拍卖的价款优先受偿的，人民法院应予支持（第三十八条）；未竣工的建设工程质量合格，承包人请求其承建工程部分折价或者拍卖的价款优先受偿的，人民法院也应予支持（第三十九条）。质量不合格是优先受偿权的实体障碍。
  3. 装饰装修工程具备折价或者拍卖条件。装饰装修工程具备折价或者拍卖条件的，装饰装修工程的承包人请求工程价款就该装饰装修工程折价或者拍卖的价款优先受偿的，人民法院应予支持（第三十七条）。
  4. 不存在有效的放弃。发包人与承包人约定放弃或者限制建设工程价款优先受偿权，损害建筑工人利益，发包人根据该约定主张承包人不享有优先受偿权的，人民法院不予支持（第四十二条）。换言之，约定放弃并非当然有效；是否损害建筑工人利益是审查重点。

受偿范围也有明确边界：承包人建设工程价款优先受偿的范围依照国务院有关行政主管部门关于建设工程价款范围的规定确定；承包人就逾期支付建设工程价款的利息、违约金、损害赔偿金等主张优先受偿的，人民法院不予支持（第四十条）。利息、违约金、损失赔偿只能作为普通债权主张，不能进入优先受偿范围。

四、十八个月起算点的确定与利息的计算

由于起算点直接决定期限是否经过，必须回到"应当给付工程价款之日"的认定规则。当事人对付款时间没有约定或者约定不明的，下列时间视为应付款时间：

  1. 建设工程已实际交付的，为交付之日；
  2. 建设工程没有交付的，为提交竣工结算文件之日；
  3. 建设工程未交付，工程价款也未结算的，为当事人起诉之日。

上述规则同时用于确定利息的起算时间——利息从应付工程价款之日开始计付（第二十七条）。由此形成两个实务后果：第一，只要没有交付也没有结算，起算点就会推迟到起诉之日，这也是部分承包人对期限产生误判的原因；第二，利息从应付之日开始计付，意味着拖延结算对发包人同样产生成本，谈判中可以据此施压。

工程款利息的计付标准方面，当事人有约定的按约定处理；没有约定的，按照同期同类贷款利率或者同期贷款市场报价利率计息（第二十六条）。

五、发包人以质量提出反诉或抗辩的应对

面对工程款请求，发包人最常见的应对是以质量不合格提出抗辩或者反诉。相关规则是一组完整的链条：

  1. 合并审理。发包人在承包人提起的建设工程施工合同纠纷案件中，以建设工程质量不符合合同约定或者法律规定为由，就承包人支付违约金或者赔偿修理、返工、改建的合理费用等损失提出反诉的，人民法院可以合并审理（第十六条）。
  2. 质量不合格时的减价。因承包人的原因造成建设工程质量不符合约定，承包人拒绝修理、返工或者改建，发包人请求减少支付工程价款的，人民法院应予支持（第十二条）。注意逻辑顺序：发包人应当先要求修理、返工、改建；承包人拒绝的，才产生减价的正当性。
  3. 发包人的过错责任。发包人提供的设计有缺陷、提供或者指定购买的建筑材料、建筑构配件、设备不符合强制性标准、直接指定分包人分包专业工程，造成建设工程质量缺陷的，应当承担过错责任；承包人有过错的，也应当承担相应的过错责任（第十三条）。
  4. 擅自使用的后果。建设工程未经竣工验收，发包人擅自使用后，又以使用部分质量不符合约定为由主张权利的，人民法院不予支持；但承包人应当在建设工程的合理使用寿命内对地基基础工程和主体结构质量承担民事责任（第十四条）。
  5. 质量争议可列共同被告。因建设工程质量发生争议的，发包人可以以总承包人、分包人和实际施工人为共同被告提起诉讼（第十五条）。

据此，承包人应对质量抗辩的要点有三个：一是核对工程是否已经擅自使用，若已使用，则发包人以使用部分质量不符合约定为由的抗辩空间大幅收窄；二是核对质量缺陷的成因，属于发包人提供设计、指定材料、指定分包所致的，应当据实抗辩并主张过错分担；三是区分质量保证金的返还与保修义务，质量保证金返还期限届满的，承包人有权请求返还，返还后不影响其继续履行保修义务（第十七条）。

六、实际施工人的主张路径与代位权

实际施工人不享有建设工程价款优先受偿权，但可以通过两条方式主张权利：

  1. 以转包人、违法分包人为被告起诉。人民法院应当依法受理（第四十三条第一款）。
  2. 以发包人为被告主张权利。人民法院应当追加转包人或者违法分包人为本案第三人，在查明发包人欠付转包人或者违法分包人建设工程价款的数额后，判决发包人在欠付建设工程价款范围内对实际施工人承担责任（第四十三条第二款）。责任范围以"发包人欠付的数额"为限，这是实际施工人主张时最容易失守的一点。

此外还有代位权路径：实际施工人依据《民法典》第五百三十五条，以转包人或者违法分包人怠于向发包人行使到期债权或者与该债权有关的从权利，影响其到期债权实现，提起代位权诉讼的，人民法院应予支持（第四十四条）。

律师提示：实际施工人诉讼中，最重要的准备工作是查清"发包人是否欠付、欠付多少"。若发包人已经付清工程款，即便转包人、违法分包人拖欠实际施工人款项，实际施工人也无法要求发包人承担责任，只能向合同相对方主张。因此诉前应当完成付款情况的证据梳理，必要时申请法院调查取证。

七、路径组合与实务操作顺序

工程款追索的关键是"顺序"而不是"选择"：

  1. 第一步：固定债权。整理施工合同、补充协议、签证与索赔文件、结算材料与往来函件，明确欠付本金与应付时间。
  2. 第二步：保全先行。在诉讼或仲裁前申请财产保全，对发包人的银行账户、在建工程或者未售房屋采取保全措施，避免胜诉后无财产可执行。
  3. 第三步：同步主张优先受偿权。主体适格且质量合格的，应当在十八个月期限内明确主张建设工程价款优先受偿权，并在诉讼请求中写明对案涉工程折价或者拍卖价款优先受偿。
  4. 第四步：应对质量抗辩。按前述五个规则逐项核对，必要时申请质量鉴定并明确鉴定范围。

需要一并提示的是，优先受偿权与商品房消费者权利、抵押权之间存在顺位关系问题，工程款优先受偿权与商品房消费者已支付价款的权利如何协调，已有专门规则，此类案件应当单独评估权利顺位。

八、常见问题

问：十八个月从什么时候开始算？

自发包人应当给付建设工程价款之日起算（《建设工程施工合同司法解释（一）》第四十一条）。付款时间没有约定或者约定不明的，已实际交付的为交付之日，没有交付的为提交竣工结算文件之日，未交付也未结算的为当事人起诉之日（第二十七条）。

问：实际施工人有优先受偿权吗？

原则上没有。建设工程价款优先受偿权的主体限于与发包人订立建设工程施工合同的承包人（第三十五条）。实际施工人应当通过第四十三条、第四十四条的路径主张权利。

问：利息、违约金能优先受偿吗？

不能。承包人就逾期支付建设工程价款的利息、违约金、损害赔偿金等主张优先受偿的，人民法院不予支持（第四十条）。优先受偿的范围限于建设工程价款。

问：发包人约定了放弃优先受偿权，还能主张吗？

关键看约定是否损害建筑工人利益。约定放弃或者限制优先受偿权并损害建筑工人利益的，发包人据此主张承包人不享有优先受偿权的，人民法院不予支持（第四十二条）。

问：工程没有竣工验收，发包人已经用了，还能以质量为由拒付吗？

发包人擅自使用后，又以使用部分质量不符合约定为由主张权利的，人民法院不予支持；但承包人仍应在建设工程的合理使用寿命内对地基基础工程和主体结构质量承担民事责任（第十四条）。

问：质量保证金什么时候能要回来？

当事人约定的质量保证金返还期限届满的；未约定返还期限的，自建设工程通过竣工验收之日起满二年；因发包人原因建设工程未按约定期限进行竣工验收的，自承包人提交工程竣工验收报告九十日后约定的返还期限届满，未约定返还期限的，自提交工程竣工验收报告九十日后起满二年（第十七条）。返还质量保证金不影响承包人继续履行保修义务。

问：优先受偿权与其他债权之间怎么排序？

承包人依据《民法典》第八百零七条享有的建设工程价款优先受偿权优于抵押权和其他债权（第三十六条）。涉及商品房消费者已支付价款的权利时，权利顺位另有规则，应结合具体情况单独评估。
