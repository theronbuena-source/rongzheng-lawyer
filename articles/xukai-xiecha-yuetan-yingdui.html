收到虚开协查函或税局约谈，老板先看清三种走向

荣郑律师 · 湖北立丰律师事务所 · 2026年11月

这不是一篇普通「税务应对」清单。协查函、约谈通知背后，同时踩着行政补税与可能转向刑事两条线。下文按律师＋税务师一起看税刑两本账的方式，帮老板先看清：函上该盯哪几行、三种走向怎么用来提问、为什么别急着按听说的口径补合同。这是阅读框架，具体会走到哪一条，需结合个案材料判断，本文不作「一定不移送」等结果承诺。

一、先分清：你收到的是哪一类纸

实务里材料名称很多：协查函、约谈/询问通知、税务事项通知、稽查检查通知、处理/处罚决定等。先归成三个问题——要你说明什么、多久用什么方式回复、有没有已经定性的处理意见——比先打听「严不严重」更有用。纸面要求可以逐项勾掉；打听来的版本常常互相矛盾。若财务与业务各执一词，更不要先对外统一一套「标准答案」——先把原件和流水固定下来，再决定说明边界。

二、三种走向对照（沟通框架，需个案判断）

为了讨论方便，把常见演进粗分为三种。它们不是法定档位，也不是必然顺序；同一案件可能反复或跳步。用它来问对问题即可：

走向（框架）大致特征老板常误判的点更该问专业人士的
说得清，行政侧收束票、货、款能对上；说明被接受；未形成需移送的判断（仍需个案确认）以为「对方不问了」就永远结束还缺哪些原始凭证？口径与账载是否一致？
行政处理：补税、滞纳金、处罚等进项转出、补税、处罚决定等出现或高度可能只谈「补多少钱」，不问事实范围怎么写进决定书金额口径？履行时点？对后续评价有何影响？
可能转向刑事出现移送相关表述、公安介入或已刑事强制措施仍按「好好补税就能私下了结」处理行政主导还是刑事主导？材料会否进入刑事卷？

硬约束两句：「可能」不是「必然」；行政补税与刑事评价的关系因案而异。深度见 《行政执法与刑事司法衔接》、《虚开增值税专用发票罪的入罪与数额标准》，本页不复述数额档位。

三、函上先盯哪几行

  1. 事项与票面识别信息——决定你要调哪一批凭证。
  2. 回复期限与方式——逾期被动；「赶工乱回」往往比晚两天更糟。
  3. 资料清单——合同、运输、入库、流水等，先盘点「有／没有／在谁手里」。
  4. 是否出现检查、稽查、涉嫌、移送等措辞——值得警惕，但不要自行脑补成定罪。
约谈通知与协查函同时出现时，按时间线钉表：哪天收到、谁签字、交了什么。口头「先补一笔」与书面不一致时，以书面为准并留存记录。

四、为什么别急着「补合同、对口径」

压力大时最常见的冲动是连夜补签合同、补运单、统一话术。风险在于：事后材料若与客观交易、资金流、物流不符，可能越描越黑；多人微信群对答案本身可能成为需解释的记录；销毁、隐匿、篡改账册会带来额外严重后果。

顺序应是：先盘点已有真实材料 → 再评估缺口 → 再决定说明策略与是否补正。补不补、怎么补，应在了解法律风险后再做。

五、约谈「自查补税」和可能移送，差在哪一步

听到「你们先自查、把税补了」，拆成三层听：事实层（问题出在哪几张票）、行政处理层（补的是税款／滞纳金／罚款，决定书怎么写）、程序层（约谈说明、立案稽查，还是已有移送信号）。

阶段观感常见动作容易忽略的
约谈／说明到场或书面说明、报送资料说明内容日后可能进卷宗
稽查／检查深入调账、询问、协查扩大范围可能从「几张票」扩到「一条线」
处理／处罚决定书、履行期限与刑事评价的关系需个案看
出现移送相关信号材料移交、公安介入可能仍按纯行政思维会延误权利行使

逃税「行政处理前置／初犯免责」不能想当然套到虚开。对照 《逃税罪的入罪标准、初犯免责与行政处理前置》。

函看不懂、票货款对不上、有人劝你「先补一笔」时：带协查函或约谈／稽查通知＋相关发票清单＋银行流水来，约 40–60 分钟，律师与税务顾问一起讲清四件事——更接近哪种讨论框架、两本账差在哪、补税利弊框架、下一步三件事。咨询参考 500 元；不承诺「一定不移送」或任何案件结果。

六、收到材料后，七天内优先做这几件

  1. 固定送达与原件——全部页扫描／拍照，含印章与附件清单。
  2. 最小应对组——老板、财务、经办业务各一人；对外口径只留一个窗口。
  3. 票、货、款三线盘点——按函件列明发票勾对，标「对得上／对不上／缺材料」。
  4. 法律与税务会诊——把函件与盘点表给律师、税务顾问同看，再准备回复包；该申请延期的依法申请。

期限以你收到的文书为准。若已有人被刑拘，改读 《虚开增值税专用发票被刑拘，家属先看懂这两份文书》 与 《收到刑事拘留通知书后的24小时》。

七、回复说明：常见翻车三点（不教成文）

本页不教你怎么写成文说明。实务里最容易翻车的，反而是这三件：

  1. 空泛表态、不指向具体票——「我司一贯合规」占版面，却对不上函件列明的号码。
  2. 把缺口编成「完整闭环」——暂时找不到的环节硬写成已履约，日后对不上更被动。
  3. 提交后自己留不住副本——说不清当时交了什么，二次沟通只能凭记忆。

说明怎么写、附件怎么排，属于带原件当面（或远程）对材料时再定的事；网上教程越细，越像把自己写成卷宗里的当事人。

协查／约谈阶段最贵的错误，往往不是「回复晚了一天」，而是做了难以逆转的事：毁账、假合同、多头对口径、向个人账户交「摆平费」。相对可逆且几乎总有用的，是固定文书、盘点票货款、统一窗口、留提交副本、尽早让律师与税务顾问看同一套材料。

八、FAQ（三问）

问：协查是不是已经按虚开立案了？答：协查常见于核查发票流向，不等于刑事立案，也不等于行政稽查结论已出。仍以文书措辞与后续动作判断。

问：约谈能不能只派财务去？答：视通知与问题范围而定。涉及业务真实性时，只派财务可能答不全；临时「谁能说谁去」更容易口径漂移。

问：下游说「你们补税我们就没事」怎么办？答：上下游利益并不自动一致。对方的安抚不能代替你对自身风险的评估。
