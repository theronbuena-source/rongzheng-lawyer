收到虚开协查函或税局约谈，老板先看清三种走向

荣郑律师 · 湖北立丰律师事务所 · 2026年11月

协查函、约谈通知、稽查文书——名字不同，但老板最怕的是同一件事：会不会从「说清楚」变成「补税」，再变成「刑事」。下文用三种走向对照，帮你先看清函上该盯哪几行、七天内先做什么、为什么别急着按听说的口径补合同。这是阅读与应对框架，具体会走到哪一条，需结合个案材料与办案阶段判断，本文不作结果承诺。

一、先分清：你收到的是哪一类纸

实务里「税局找上门」的材料名称很多，常见包括：协查相关函件、约谈/询问通知、税务事项通知、责令限期改正、稽查立案/检查通知，以及后续处理、处罚决定等。名字不统一，但阅读时可以先归成三类问题：

  1. 要你说明什么？某几张票、某个受票方/开票方、某个所属期，还是笼统的「虚开嫌疑」。
  2. 给你多长时间、通过什么方式回复？书面说明、到场说明、报送资料清单。
  3. 有没有已经定性的处理意见？还是仍在「查清事实」阶段。

把纸面要求看准，比先找人「托关系打听严重不严重」更有用。打听来的版本常常互相矛盾；纸面要求可以逐项勾掉。

二、三种走向对照（沟通框架，需个案判断）

为了讨论方便，可以把常见演进粗分为三种走向。它们不是法律上的固定「档位」，也不是时间表上的必然顺序；同一案件可能在中间反复，也可能跳步。用它来问对问题即可：

走向（框架）大致特征老板常误判的点更该问专业人士的问题
说得清，行政侧收束交易与票、货、款能对上；说明与资料被接受；未形成需移送的判断（仍需个案确认）以为「对方不问了」就永远结束，忽视留痕与后续抽查还缺哪些原始凭证？说明口径与账载是否一致？
行政处理：补税、滞纳金、处罚等进项转出、补税、处罚决定等行政后果出现或高度可能只谈「补多少钱」，不问事实范围会不会被写进决定书金额口径是什么？履行时点？对后续评价有何影响？
可能转向刑事出现移送相关表述、公安介入、或已采取刑事强制措施仍按「好好补税就能私下了结」处理，延误程序权利现在是行政主导还是刑事主导？材料会否被用作刑事证据？

读表时请记住两句硬约束：第一，「可能」不是「必然」；第二，行政补税与刑事评价的关系因案而异，详见站内 《行政执法与刑事司法衔接》 与 《虚开增值税专用发票罪的入罪与数额标准》，本页不复述具体数额档位。

三、函上先盯哪几行

  1. 事项与票面识别信息。发票代码号码、开票方/受票方名称、所属期——决定你要调哪一批凭证。
  2. 回复期限与方式。逾期不回本身就会被动；但「赶工乱回」往往比晚两天更糟。
  3. 要求报送的资料清单。合同、运输、入库、资金流水、邮箱/微信沟通记录等，先按清单盘点「有/没有/在谁手里」。
  4. 是否出现检查、稽查、涉嫌、移送等措辞。措辞变化值得警惕，但不要自行脑补成定罪结论。
  5. 联系人与签收记录。保留送达回证、邮件签收、快递底单，避免事后说不清「到底收到没有」。
若同时出现约谈通知与协查函，按时间线钉在一张表上：哪天收到、谁签字、交了什么、口头怎么说的。口头「先补一笔」与书面要求不一致时，以书面为准并留存记录。

四、为什么别急着「补合同、对口径」

压力大的时候，最常见的冲动是：连夜找业务员补签合同、补运单、统一话术。风险在于——

  1. 事后形成的材料，若与客观交易、资金流、物流不符，可能把「说不清」变成「越描越黑」。
  2. 多人微信群里对答案，本身可能成为后续需要解释的沟通记录。
  3. 销毁、隐匿、篡改账册凭证会带来额外严重后果，绝不是「为了过关」的选项。

正确顺序通常是：先盘点已有真实材料 → 再评估缺口性质 → 再决定说明策略与是否补正。补不补、怎么补，应在了解法律风险后再做，而不是先补完再找人看。

五、约谈「自查补税」和可能移送，差在哪一步

约谈场景里，经常听到「你们先自查、把税补了」。听的时候建议拆成三层，而不是只听「补」这个字：

  1. 事实层：对方认为问题出在哪几张票、哪个环节？你是否认可、能否证明？
  2. 行政处理层：若补税，补的是税款、滞纳金还是罚款？决定书怎么写事实？
  3. 程序层：当前是约谈说明、立案稽查，还是已出现移送相关信号？
阶段观感常见动作老板容易忽略的
约谈 / 说明到场或书面说明、报送资料说明内容日后可能进入卷宗；口径要经得起核对
稽查 / 检查深入调账、询问、协查扩大事实范围可能从「几张票」扩到「一条线」
处理 / 处罚决定书、履行期限履行方式与时点；与刑事评价的关系需个案看
出现移送相关信号材料移交、公安介入可能仍按纯行政思维「私下搞定」会延误权利行使

逃税语境下存在与「行政处理前置/初犯免责」相关的特殊规则框架，不能想当然套用到虚开。对照阅读 《逃税罪的入罪标准、初犯免责与行政处理前置》，避免自我诊断。

六、收到材料后七天内，建议做什么

  1. Day 1：固定送达与原件。扫描/拍照全部页，含印章与附件清单；建文件夹按日期命名。
  2. Day 1–2：成立最小应对组。老板、财务负责人、经办业务各一人；对外口径指定一人，避免多头回复。
  3. Day 2–3：票、货、款三线盘点。按函件列明的发票，逐张勾对合同、入库/运输、付款回款；标出「对得上 / 对不上 / 缺材料」。
  4. Day 3–4：法律与税务会诊（建议）。把函件与盘点表给律师、税务顾问同看，先判断更接近三种走向中的哪一种讨论框架。
  5. Day 4–6：准备回复包。说明逻辑、附件目录、原件与复印件清单；该申请延期的依法申请，而不是沉默。
  6. Day 7：复盘风险点。有没有人已经在补合同？有没有群聊对口径？立刻停下并评估影响。

七天不是魔法数字，而是「别拖到最后一晚才想起来找材料」的纪律。期限以你收到的文书为准。

七、已经有人被带走时，读哪一篇

若同事或家属已经收到刑事拘留通知书，应对重点转到刑事程序与两份文书对照，请改读枢纽页 《虚开增值税专用发票被刑拘，家属先看懂这两份文书》，并参阅 《收到刑事拘留通知书后的24小时》。行政侧材料仍要保管好，但动作优先级会变化。

八、财务与业务怎么分工，才不会互相拆台

协查/约谈压力下，财务想「先把进项转了」，业务想「先把客户稳住」，老板想「先找人压一压」。三个方向同时推进，最容易出现材料打架。建议明确分工：

  1. 财务：只负责导出与保管——发票清单、申报表、进销项明细、银行流水；不擅自做「美化分录」。
  2. 业务：只负责还原交易事实——订单、验收、运输、邮件；不组织客户出具「假证明」。
  3. 老板/法务窗口：统一对外回复与内部会议纪要；重大说明提交前必须过专业人士。

若公司有多家关联主体互相开票，盘点范围可能超出函件字面列示的几张票。这时更不要自行缩小范围「只解释这几张」——应先评估风险再决定说明边界。

九、回复说明怎么写才不像「作文」

一份有用的说明，通常具备四个零件；缺一就会变成空泛表态：

  1. 指向具体票。写清发票号码/代码或清单附件，避免「我司一贯合规」式开头占版面。
  2. 描述交易要素。标的、数量、价格形成、履约与结算；有就写有，没有就写「正在查找」，不要编。
  3. 附证据目录。每个主张对应附件编号；原件与复印件分开列。
  4. 承认不确定处。对暂时无法核对的环节明确标注，比硬编「完整闭环」更安全。

说明提交后，内部应保留「提交包」完整副本（PDF+附件压缩包哈希或文件列表），防止日后说不清当时交了什么。

十、FAQ（老板/财务高频六问）

问一：协查是不是已经按虚开立案了？答：协查常见于核查发票流向，不等于刑事立案，也不等于行政稽查结论已出。仍要以文书措辞与后续动作判断，需结合个案。

问二：约谈能不能只派财务去？答：视通知要求与问题范围而定。若涉及业务真实性，只派财务可能答不全；若临时决定「谁能说谁去」，更容易口径漂移。出发前应完成材料盘点与要点清单。

问三：下游说「你们把税补了我们就没事」怎么办？答：上下游利益并不自动一致。对方的安抚性表述不能代替你对自身风险的评估；是否协助对方说明、如何协助，要单独判断。

问四：已经按约谈要求补了一笔，还需要留档案吗？答：需要。完税/缴款凭证、决定书、银行回单、沟通记录都应归档。补缴事实本身也要能说明「补的是哪一段、哪一笔」。

问五：能不能公开网上发声明澄清？答：一般不建议在事实未厘清时对外发布案情细节。舆情与客户沟通可用极简口径，细节走程序内渠道。

问六：和家属枢纽页怎么配合用？答：人尚未被采取刑事强制措施时，优先用本页做行政侧应对；一旦出现刑拘通知书，请转 家属枢纽页，两页通过内链互相跳转，避免各说各的。

十一、三种「听起来很懂」的建议，为什么要打问号

圈子里流传的应对建议很多，下面三类尤其常见。本文不是说它们「一定错」，而是提醒：每条背后都有前提，前提不成立时照做会伤到自己。

  1. 「先把税补上，态度好就行。」补税在不少案件里有意义，但「补多少、补哪一段、决定书怎么写事实」决定了你留下的书面画像。只补钱不核对事实范围，可能等于用真金白银确认了一版对你不利的叙述。
  2. 「找下游出个情况说明，证明有真实交易。」真实交易当然要靠证据证明；但若下游本身也在被协查，双方临时互开「完美说明」，可信度与风险都要评估。证据应优先来自交易当时形成的记录，而不是案发后互写的文书。
  3. 「先别请律师，请了显得心虚。」依法委托专业人士本身是正常权利，越早梳理材料，越不容易在约谈里被动。是否在某次约谈中带律师到场，可以视通知与策略决定，但「完全不咨询」往往更危险。

十二、和站内其他文章怎么配合读

建议阅读顺序（可按你的处境裁剪）：

  1. 先用本页判断：材料类型、三种走向框架、七天动作。
  2. 需要理解虚开评价框架时，读 虚开专题文（含情形与数额标准，以该文为准）。
  3. 行政与刑事碰头时，读 行刑衔接文。
  4. 有人拿逃税「免责」说法来安慰你时，先读 逃税专题文，再决定能不能类推（通常不能直接套）。
  5. 若已出现刑拘，转 家属枢纽页 与 拘留通知书24小时文。

这样安排的目的，是让搜索引擎与读者都落到「同一套题」：外站日更文末可以回链本页；本页再把深度法义交给存量专题，而不是在获客页里堆法条数字。

十三、小结：先做「可逆」的事

协查与约谈阶段，最贵的错误往往不是「回复晚了一天」，而是做了难以逆转的事：毁账、假合同、多头对口径、向个人账户交「摆平费」。相对可逆、且几乎总是有用的，是：固定文书、盘点票货款、统一窗口、留下提交副本、尽早让律师与税务顾问看同一套材料。

三种走向表格只是提问工具。真正决定你落在哪一侧的，是事实能不能支撑说明，以及程序已经走到哪一步——这两件事都无法靠心情或传言替代。

可以带协查函 / 约谈通知来梳理走向

建议携带：协查函或约谈/稽查相关文书原件（或清晰照片）、已整理的票货款对照表（有最好）。约 40–60 分钟看材料，重点讲清：更接近哪种讨论框架、函上关键几行怎么理解、七天内优先动作、补税相关利弊框架与下一步三件事。不承诺「一定不移送」或任何案件结果。
