债权人撤销权的行使条件、一年与五年除斥期间及与执行程序的衔接

荣郑律师 · 湖北立丰律师事务所 · 2026年10月

一、结论先行：四个要件、两个除斥期间、一条衔接路径

债权人撤销权是债的保全制度，用于把债务人转移到他人名下的财产"拉回"债务人的责任财产。以《民法典》第五百三十八条、第五百三十九条和《民法典合同编通则解释》第四十二条至第四十六条为依据，可以归纳为四句话：

  1. 要件一——合法有效的债权：债权须真实合法，原则上应当是既存债权；无需已经到期，也无需已经取得生效法律文书确认（《民法典合同编通则解释》第四十条第二款的精神同样适用于撤销权诉讼的受理审查）。
  2. 要件二——存在诈害行为：无偿处分财产权益，或者以明显不合理的价格有偿处分财产权益（《民法典》第五百三十八条、第五百三十九条）。
  3. 要件三——影响债权实现：债务人因该行为陷于"无资力"，即不足以清偿债权。
  4. 要件四——主观要件（仅有偿行为需要）：相对人知道或者应当知道该情形。

两个除斥期间必须同时满足：《民法典》第五百四十一条规定，撤销权自债权人知道或者应当知道撤销事由之日起一年内行使；自债务人的行为发生之日起五年内没有行使的，撤销权消灭。一年与五年同属除斥期间，不适用中止、中断、延长（《民法典》第一百九十九条）。也就是说，即使债权人在知道撤销事由的一年内起诉，若距债务人的处分行为发生已满五年，撤销权同样消灭。

一条衔接路径是：《民法典合同编通则解释》第四十六条第三款明确，债权人依据其与债务人的诉讼、撤销权诉讼产生的生效法律文书申请强制执行的，人民法院可以就债务人对相对人享有的权利采取强制执行措施以实现债权人的债权；债权人在撤销权诉讼中申请对相对人的财产采取保全措施的，人民法院依法予以准许。

二、两类可撤销行为：无偿处分与明显不合理价格

《民法典》把诈害行为分成两类，构成要件与举证责任差别明显，实务中首先要做的是归类：

比较项无偿处分（第五百三十八条）明显不合理价格的有偿处分（第五百三十九条）
典型形态放弃债权、放弃债权担保、无偿转让财产、恶意延长到期债权的履行期限以明显不合理的低价转让财产、以明显不合理的高价受让他人财产、为他人的债务提供担保
相对人主观要件不需要，不问相对人是否知情需要，相对人知道或者应当知道该情形
举证重点行为无偿 + 影响债权实现价格明显不合理 + 影响债权实现 + 相对人恶意
扩展形态—互易财产、以物抵债、出租或者承租财产、知识产权许可使用等（合同编通则解释第四十三条）

《民法典合同编通则解释》第四十三条把"以明显不合理的价格实施互易财产、以物抵债、出租或者承租财产、知识产权许可使用等行为"一并纳入第五百三十九条的适用范围。需要注意的是，以物抵债、租赁、知识产权许可这类不转移所有权、只转移使用价值的交易同样可能被撤销，这一点在实践中常被忽略。

实务中还有一种隐蔽形态：协议上约定了"合理"对价，实际并未支付。此种"名为有偿、实为无偿"的安排，应当按无偿处分处理，由债务人和相对人就对价的实际支付情况承担举证责任；仅凭合同约定不能证明对价真实支付。

三、债权要件：合法、既存、无需届期、种类不限

撤销权的前提是债权人对债务人享有合法有效的债权。审查要点有四项：

  1. 合法性：债权本身的产生须合法，赌债等违法之债不能作为撤销权的基础。
  2. 既存性：原则上是既存债权；但在后债权特定具体、发生可能性极高，且债务人在处分财产时明知该债权即将发生、处分行为将影响其实现的情况下，司法实践中也存在将后债权纳入撤销权行使范围的做法。
  3. 无需届期：债权履行期是否届满，不是行使撤销权的前置条件。
  4. 种类不限：可撤销所保护的债权以财产给付为目的，既可以是约定之债也可以是法定之债，不限于金钱债权，还包括可转化为金钱债权的损害赔偿请求权、折价补偿请求权等。
实务要点：债权人尚未对债务人提起诉讼，或者诉讼尚在审理中，债务人以此抗辩债权人不具备撤销权诉讼主体资格的，人民法院不予支持。因此不必等到基础债权判决生效再打撤销权官司，但两条诉讼的进度与证据要统筹安排。

四、主观要件与举证责任分配

无偿处分下不要求相对人恶意，这一点对债权人极为有利。有偿处分下则要求相对人知道或者应当知道该情形。主观恶意属于心理状态，债权人难以直接证明，审判实践中一般采用推定的方法：以明显不合理的低价转让或者不合理高价受让，相对人显然应当知道这不是正常交易，一般可推定其知道或者应当知道该交易会影响债权的实现；相对人主张自己善意的，应当举证证明，例如债务人向其提供了急需资金、存在重大投资回报等正当理由。

举证责任的另一处关键分配是对价实际支付的事实。交易凭证的原始资料一般由交易当事人掌握，因此在审查"价格是否明显不合理"以及对价是否真实支付时，由债务人、相对人举证更为合理。付款凭证应当形成证据链：以银行转账方式支付的，收款人账户应与债务人账户一致，不一致的应作出合理解释；以大额现金支付的，不能仅凭收据、收条认定，还应说明现金的来源与交付细节。

五、"明显不合理"的量化标准：百分之七十与百分之三十

《民法典合同编通则解释》第四十二条规定了量化方法：对于《民法典》第五百三十九条规定的"明显不合理"的低价或者高价，人民法院应当按照交易当地一般经营者的判断，并参考交易时交易地的市场交易价或者物价部门指导价予以认定。

  • 低价：转让价格未达到交易时交易地的市场交易价或者指导价百分之七十的，一般可以认定为"明显不合理的低价"；
  • 高价：受让价格高于交易时交易地的市场交易价或者指导价百分之三十的，一般可以认定为"明显不合理的高价"。
  • 例外：债务人与相对人存在亲属关系、关联关系的，不受前述百分之七十、百分之三十的限制。

这组数字是"一般可以认定"的参考线，不是绝对标准。价格偏离未达线但结合交易背景足以认定不合理的，仍有可能被认定；反之，偏离达到线但存在正当商业理由的，也需要综合判断。实操中应当准备市场价格的证明材料，如同期同类房屋的网签价、同类股权的评估报告、行业价格指数等。

六、除斥期间：一年与五年的双重限制

《民法典》第五百四十一条的两句规定构成双重限制，必须同时满足：

  1. 一年：自债权人知道或者应当知道撤销事由之日起一年内行使。起算点是"知道或者应当知道"，需要结合债权人何时取得相关信息判断。
  2. 五年：自债务人的行为发生之日起五年内没有行使的，撤销权消灭。这是客观上限，与债权人是否知情无关。

《民法典》第一百九十九条明确，法律规定或者当事人约定的撤销权、解除权等权利的存续期间，除法律另有规定外，自权利人知道或者应当知道权利产生之日起计算，不适用有关诉讼时效中止、中断和延长的规定，存续期间届满，权利消灭。因此撤销权不能通过发函催告、提起诉讼以外的行为保全。最稳妥的做法是在发现债务人转移财产后尽快起诉，不要寄望于协商拖延。

七、与执行程序的衔接：管辖、被告、保全与合并审理

债权人撤销权纠纷不是普通合同纠纷，其请求权基础源自法律的直接规定。程序要点如下：

  1. 被告：《民法典合同编通则解释》第四十四条第一款规定，债权人依据《民法典》第五百三十八条、第五百三十九条提起撤销权诉讼的，应当以债务人和债务人的相对人为共同被告。
  2. 管辖：由债务人或者相对人的住所地人民法院管辖，但是依法应当适用专属管辖规定的除外。注意这里适用一般地域管辖，不适用合同履行地等特别管辖规则。
  3. 合并审理：两个以上债权人就债务人的同一行为提起撤销权诉讼的，人民法院可以合并审理（第四十四条第二款）；债权人请求受理撤销权诉讼的人民法院一并审理其与债务人之间的债权债务关系，属于该法院管辖的，可以合并审理（第四十六条第二款）。
  4. 撤销范围：被撤销行为的标的可分，当事人主张在受影响的债权范围内撤销的，人民法院应予支持；标的不可分，债权人主张全部撤销的，人民法院应予支持（第四十五条第一款）。
  5. 后果处理：债权人在撤销权诉讼中同时请求相对人向债务人承担返还财产、折价补偿、履行到期债务等法律后果的，人民法院依法予以支持（第四十六条第一款）。
  6. 费用：债权人行使撤销权所支付的合理的律师代理费、差旅费等费用，可以认定为《民法典》第五百四十条规定的"必要费用"（第四十五条第二款）。
  7. 与执行的衔接：债权人依据生效法律文书申请强制执行的，人民法院可以就债务人对相对人享有的权利采取强制执行措施；撤销权诉讼中申请对相对人的财产采取保全措施的，人民法院依法予以准许（第四十六条第三款）。
执行实务提示：债务已经进入执行程序却发现财产已被低价转出的，撤销权诉讼与执行程序可以并行。较为常见的组合是在撤销权诉讼中同时对相对人的财产申请保全，胜诉后凭撤销权判决与基础债权文书一并申请执行，从而避免"撤销了却拿不到钱"的落差。

八、常见问题与依据核验

问：债务人把房子无偿送给子女，债权人可以直接申请执行那套房子吗？

不能直接执行登记在子女名下的房产。应先依《民法典》第五百三十八条提起撤销权诉讼，以债务人和其子女为共同被告；撤销后凭生效法律文书申请执行。

问：债权人只欠我一笔未到期的借款，能行使撤销权吗？

可以。债权履行期是否届满不是行使撤销权的前置条件，但须债权合法有效、内容特定。

问：债务人以市场价七五折把设备卖给关联公司，算不算明显不合理低价？

七五折未低于百分之七十的参考线，但从价格本身看尚未达到一般认定标准。若债务人与相对人存在关联关系，则不受百分之七十、百分之三十的限制，仍可结合其他证据认定其构成明显不合理低价（《民法典合同编通则解释》第四十二条）。

问：撤销权的一年期间能不能通过发律师函中断？

不能。依《民法典》第一百九十九条，该期间为除斥期间，不适用中止、中断和延长。必须在该期间内提起诉讼。

问：撤销权诉讼要交多少诉讼费，律师费能不能让对方承担？

诉讼费按财产案件标准缴纳。债权人行使撤销权所支付的合理律师代理费、差旅费等，可以认定为民法典第五百四十条规定的"必要费用"，由债务人负担（《民法典合同编通则解释》第四十五条第二款）。

法条与依据核验：《中华人民共和国民法典》第一百五十七条（民事法律行为被撤销后的返还与折价补偿）、第一百九十九条（除斥期间不适用中止、中断和延长）、第五百三十八条（无偿处分财产权益时的撤销权）、第五百三十九条（以明显不合理价格处分时的撤销权）、第五百四十条（撤销权的行使范围与必要费用）、第五百四十一条（一年与五年除斥期间）；《最高人民法院关于适用〈中华人民共和国民法典〉合同编通则若干问题的解释》（法释〔2023〕13号）第四十条第二款、第四十二条、第四十三条、第四十四条、第四十五条、第四十六条。特别说明：本文所引《民法典》条文序号依2021年1月1日起施行的现行文本标注；合同编通则解释自2023年12月5日起施行。本文第三节关于"后债权"能否行使撤销权、第四节关于相对人恶意的推定方法、第五节关于"明显不合理"价格的具体判断，均系审判实践的通常做法与个案裁量事项，各地裁判尺度并不完全统一，已在正文逐处标注"实务中存在争议"或说明其为参考线而非绝对标准；本文不引用任何具体案号，办理具体案件时应结合交易背景与当地裁判倾向判断，并请以全国人大、最高人民法院官方公布文本为准。
